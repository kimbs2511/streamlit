# 🎬 KOBIS 영화 시장 분석 프로젝트

영화진흥위원회 KOBIS 개봉 영화 데이터를 기반으로 **국내 영화 시장의 변화와 특징을 분석하고 시각화한 프로젝트**입니다.

Jupyter Notebook을 활용하여 데이터를 전처리·탐색하고, 분석 결과를 바탕으로 **Streamlit 웹 대시보드**를 구현했습니다.

## 📌 프로젝트 개요

* **분석 대상**: 2008년 ~ 2026년 극장 개봉 영화
* **분석 목적**: 국내 영화 시장의 장기적인 변화와 관객 특성 탐색
* **분석 환경**: Python / Jupyter Notebook
* **대시보드**: Streamlit
* **주요 파일**

  * `kobis.ipynb` : 데이터 전처리 및 탐색적 데이터 분석
  * `kobis.py` : 분석 결과를 시각화한 Streamlit 대시보드

---

## 🔍 주요 분석 내용

### 1. 기간별 흥행 영화 분석

사용자가 선택한 연도 범위를 기준으로 전국 관객수가 많은 영화를 분석합니다.

대시보드에서는 조회 기간 내 **최고 인기 영화와 관객 수**를 KPI 형태로 제공하며, 상위 10개 영화의 상세 정보를 확인할 수 있습니다.

주요 정보:

* 영화명
* 영화 형태
* 국적
* 전국 관객수
* 서울 관객수
* 장르
* 관람등급
* 개봉연도
* 개봉월

---

### 2. 국내·해외 영화 비율

조회 기간에 개봉한 영화를 국내외 구분에 따라 집계하여 영화 시장의 구성 비율을 확인합니다.

이를 통해 특정 기간에 **한국 영화와 해외 영화가 전체 개봉작에서 어느 정도의 비중을 차지했는지** 비교할 수 있습니다.

---

### 3. 장르별 영화 분포

개봉 영화를 장르별로 집계하여 어떤 장르의 영화가 많이 개봉했는지 분석합니다.

장르별 개봉 편수를 비교하여 국내 극장 영화 시장의 장르 구성을 살펴볼 수 있습니다.

---

### 4. 서울 관객 집중도 분석

연도별 전체 관객 중 **서울 관객이 차지하는 비율**을 계산하고, 전국 인구 중 서울 인구가 차지하는 비율과 비교합니다.

이를 통해 단순 관객 수뿐만 아니라 인구 규모를 함께 고려하여 영화 관람객의 서울 집중 현상을 살펴봅니다.

---

### 5. 연도별 영화 개봉 추이

연도별 개봉 영화 수를 집계하여 2008년 이후 극장 개봉 영화 편수가 어떻게 변화했는지 확인합니다.

이를 통해 영화 시장 규모의 장기적인 변화를 탐색합니다.

## 📓 `kobis.ipynb`

Jupyter Notebook 환경에서 KOBIS 데이터를 불러와 분석에 필요한 형태로 가공하고 탐색하기 위한 파일입니다.

주요 역할은 다음과 같습니다.

1. 원본 데이터 확인
2. 필요한 컬럼 선정
3. 결측치 및 데이터 타입 확인
4. 개봉연도·개봉월 등 분석 변수 생성 및 확인
5. 전국/서울 관객 데이터 분석
6. 영화별 흥행 데이터 탐색
7. 장르 및 국내외 영화 분포 분석
8. Streamlit 대시보드에 사용할 분석 로직 검증

Notebook에서 분석 및 검증한 내용을 기반으로 `kobis.py`에서 대시보드 형태로 구현했습니다.

## 🖥️ `kobis.py`

분석 결과를 웹에서 확인할 수 있도록 구현한 Streamlit 애플리케이션입니다.

주요 라이브러리:

```python
import streamlit as st
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt
import koreanize_matplotlib
import numpy as np
```

주요 기능:

* CSV 데이터 로딩 및 캐싱
* UTF-8 / CP949 인코딩 대응
* 분석 기간 선택
* 전국 관객수 기준 영화 순위 산출
* 국내외 영화 비율 시각화
* 장르별 영화 분포 시각화
* 서울 관객 비율과 서울 인구 비율 비교
* 연도별 영화 개봉 편수 시각화

## 🚀 실행 방법

### 1. Repository Clone

```bash
git clone https://github.com/kimbs2511/streamlit.git
cd streamlit
```

### 2. 패키지 설치

`uv`를 사용하는 경우:

```bash
uv sync
```

### 3. Streamlit 실행

```bash
uv run streamlit run kobis.py
```

또는 가상환경이 활성화되어 있다면:

```bash
streamlit run kobis.py
```

실행 후 브라우저에서 대시보드를 확인할 수 있습니다.

```text
http://localhost:8501
```

## 💡 분석 관점

본 프로젝트는 단순히 흥행 영화의 순위를 확인하는 것에서 벗어나 다음과 같은 질문을 탐색하는 것을 목표로 합니다.

> **2008년 이후 국내 극장 영화 시장은 어떻게 변화했는가?**

이를 위해 개봉 영화 수, 영화 장르, 국내외 영화 구성, 관객 규모 및 지역별 관객 집중도를 함께 살펴봅니다.

특히 서울 관객 비율을 서울 인구 비율과 비교하여 **인구 규모 이상의 영화 관람 집중 현상이 나타나는지** 탐색합니다.

## ⚠️ 분석 시 유의사항

* 영화 개봉 편수와 관객수는 영화 시장의 규모를 보여주는 지표이지만 영화 산업 전체의 성과를 의미하지는 않습니다.
* 서울 관객 비율과 서울 인구 비율의 비교는 지역별 영화 소비 차이를 탐색하기 위한 지표이며 직접적인 인과관계를 의미하지 않습니다.
* 2026년 데이터는 연간 데이터가 완전히 집계되지 않은 시점의 자료일 수 있으므로 다른 연도와 직접 비교할 때 주의가 필요합니다.
* 장르 분류 및 영화 정보는 원본 데이터의 분류 기준을 따릅니다.
